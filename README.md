### 🛠 Чем занимаюсь

- **Telegram-боты** — от учебных до рабочих: модерация, мониторинг камер с распознаванием объектов, личные помощники. TypeScript + grammY, Python + aiogram.
- **Свой сервер** — Fedora + Podman, всё в контейнерах, автообновление из GitHub Actions, резервные копии.
- **Домашняя сеть** — OpenWrt и свой DNS с фильтрацией рекламы.
- **Android TV** — лаунчер без рекламы с виджетами Home Assistant и Immich.
